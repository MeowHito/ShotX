3 ขั้นตอน เริ่มได้ทันที

01

ถ่ายและอัปโหลด

Desktop App monitor โฟลเดอร์ ภาพใหม่ sync ขึ้น Cloud ทันที AI เริ่ม tag ใบหน้าอัตโนมัติ

02

แขกสแกน QR

วาง QR Code ในงาน แขกสแกนผ่านมือถือ ไม่ต้องโหลด App เปิดใน Browser ได้เลยทุก OS

03

Selfie → รับภาพทันที

ถ่าย Selfie 1 รูป AI ค้นหาทุกภาพที่มีใบหน้าตัวเอง ดาวน์โหลดได้ฟรีทันที

ฟีเจอร์

ครบทุกอย่างที่ต้องการ

🤖

AI Face Recognition

InsightFace (self-hosted) detect และ index ใบหน้าอัตโนมัติ แม่นยำ 99% ข้อมูลไม่ออกนอก server

⚡

Real-time Sync

Desktop App monitor โฟลเดอร์ ภาพใหม่ขึ้น Gallery ทันที แขกเห็นระหว่างงานยังไม่จบ

📱

ไม่ต้องโหลด App

แขกเปิดผ่าน Browser ได้เลย QR → Selfie → ดาวน์โหลด ภายใน 30 วินาที ทุก iOS/Android

🏷️

Watermark อัตโนมัติ

ใส่ลายน้ำโลโก้หรือชื่อช่างภาพลงภาพทุกรูปอัตโนมัติเมื่อดาวน์โหลด ตั้งตำแหน่งและขนาดได้

🎯

Multi-Event QR

สร้าง QR Code เฉพาะแต่ละงาน จัดการหลาย Event พร้อมกันในบัญชีเดียว

📊

Analytics

ดูสถิติ views, downloads, Selfie searches และการใช้ Storage แบบ real-time
