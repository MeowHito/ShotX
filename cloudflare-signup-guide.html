คู่มือสมัคร Cloudflare สำหรับทีมบัญชี

ใช้สำหรับเว็บ ShotX (snap.action.in.th) · ทำแค่ 6 ขั้น ใช้เวลาประมาณ 15–20 นาที · ส่วนเทคนิคทีมไอทีจะทำต่อเอง

ใช้ Cloudflare ทำอะไร
  • R2: ที่เก็บรูปทั้งหมดของเว็บ และ backup ฐานข้อมูล
  • Turnstile: กันบอตเข้ามายิงเว็บ ใช้ฟรี
ห้ามทำ
  • ห้ามส่งรหัสผ่าน รหัส 2FA หรือข้อมูลบัตรทางแชต อีเมล หรือ LINE ให้ใคร รวมถึงทีมไอที
  • ไม่ต้องสร้าง API token หรือ bucket เอง ทีมไอทีจะทำ
  • ไม่ต้องย้ายโดเมนมาไว้ที่ Cloudflare และไม่ต้องสมัครแพ็กเกจ Pro หรือ Business
1

สมัครบัญชีด้วยอีเมลของบริษัท

  1. เข้า https://dash.cloudflare.com/sign-up
  2. ใช้อีเมลกลางของบริษัท เช่น it@ หรือ accounting@ ไม่ใช้อีเมลส่วนตัวของพนักงาน ถ้าพนักงานคนนั้นลาออก บริษัทจะยังเข้าบัญชีได้
  3. ตั้งรหัสผ่านยาวอย่างน้อย 16 ตัว ไม่ซ้ำกับที่อื่น แล้วเก็บไว้ในที่จัดการรหัสผ่านของบริษัท
  4. เปิดอีเมลยืนยันจาก Cloudflare แล้วกดยืนยัน (Verify email)

ถ้า Cloudflare ถามว่าจะเพิ่มเว็บไซต์หรือโดเมน ให้กดข้ามไปได้เลย

2

เปิดการยืนยันตัวตนสองชั้น (2FA) · สำคัญมาก

  1. กดรูปคนมุมขวาบน → Profile → Authentication
  2. เปิด Two-Factor Authentication แล้วสแกน QR ด้วยแอป Authenticator ในมือถือ เช่น Google Authenticator หรือ Microsoft Authenticator
  3. Cloudflare จะให้ Backup codes มาชุดหนึ่ง ให้ดาวน์โหลดเก็บไว้ในที่ปลอดภัย ถ้ามือถือหาย ต้องใช้ code พวกนี้เข้าบัญชี

บัญชีนี้ถือข้อมูลรูปของลูกค้าทั้งหมด ถ้าไม่มี 2FA แค่รหัสผ่านรั่วก็เข้าบัญชีได้แล้ว

3

ใส่ข้อมูลบริษัทและบัตรที่ใช้จ่ายเงิน

  1. เมนูซ้าย → Manage Account → Billing
  2. Billing profile: ใส่ชื่อบริษัท ที่อยู่ และอีเมลรับใบแจ้งหนี้ ควรเป็นอีเมลของทีมบัญชี
  3. Payment methods → Add Payment Method → ใส่บัตรเครดิตหรือเดบิตของบริษัท
    รับบัตร Visa/Mastercard, PayPal, Apple Pay, Google Pay และ UnionPay
  4. ธนาคารอาจส่ง OTP มาให้ยืนยันบัตร ให้กรอกให้เรียบร้อย

ต้องใส่บัตรก่อนขั้นที่ 4 เคยมีคนเจอปัญหาว่า ถ้าไปเปิด R2 ก่อนใส่บัตร หน้าจอจะวนกลับไปมา ใส่บัตรไม่ได้

4

เปิดใช้ R2 (ที่เก็บรูป)

  1. เมนูซ้าย → Storage & databases → R2 → Overview
  2. กดซื้อหรือเปิดใช้ R2 (Purchase R2 / Add R2) แล้วทำตามขั้นตอนชำระเงินจนเสร็จ
  3. เสร็จแล้วจะเห็นหน้า R2 Overview ที่ยังไม่มี bucket ปล่อยไว้แบบนั้นได้เลย ทีมไอทีจะสร้างเอง

R2 จ่ายตามที่ใช้จริง ไม่มีค่ารายเดือนตายตัว มีโควตาฟรีให้ทุกเดือน (ดูประมาณการค่าใช้จ่ายด้านล่าง)

5

เชิญคนจากทีมไอทีเข้าบัญชี

  1. เมนูซ้าย → Manage Account → Members → Invite
  2. ใส่อีเมลของคนในทีมไอทีที่จะตั้งค่าระบบ
  3. เลือกสิทธิ์ (Role) เป็น Administrator และให้ครอบคลุมทั้งบัญชี (All domains / account-wide) ห้ามเลือก Super Administrator
  4. กดส่งคำเชิญ คนที่ถูกเชิญต้องสมัครบัญชี Cloudflare ของตัวเองและเปิด 2FA เหมือนกัน

ทำแบบนี้ ไม่ต้องให้รหัสผ่านบัญชีบริษัทกับใคร และถ้าคนนั้นออกไป ก็กดลบสิทธิ์ได้ทันที

6

ส่งข้อมูลนี้กลับให้ทีมไอที

ข้อมูลพวกนี้ไม่ใช่ความลับ ส่งทางแชตได้

  • ☐ อีเมลที่ใช้สมัครบัญชี Cloudflare
  • ☐ Account ID: อยู่ในหน้า R2 Overview ด้านขวา หรือหน้าแรกของบัญชี เป็นตัวอักษรยาว 32 ตัว
  • ☐ ยืนยันว่าเปิด R2 เรียบร้อยแล้ว
  • ☐ ยืนยันว่าส่งคำเชิญให้ใครไปแล้ว และคนนั้นรับคำเชิญแล้ว
  • ☐ ยืนยันว่าเปิด 2FA แล้ว และเก็บ backup codes เรียบร้อยแล้ว

ประมาณการค่าใช้จ่าย R2

ประมาณการสำหรับงานวันละ 2,000 รูป 3 วัน (6,000 รูป) รวมรูปย่อและ backup ใช้พื้นที่ประมาณ 80–100 GB
